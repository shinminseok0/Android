# 📱 Android Shopping App

안드로이드 기반으로 개발된 모바일 쇼핑 애플리케이션입니다.
사용자는 다양한 스마트폰 상품을 조회하고, 장바구니에 담아 구매까지 진행할 수 있습니다.

---

## 🚀 프로젝트 소개

이 프로젝트는 Android 환경에서 동작하는 쇼핑 앱으로,
상품 조회부터 결제까지의 기본적인 전자상거래 기능을 구현하는 것을 목표로 합니다.

---

## 🛠️ 기술 스택

* **Language**: Java / Kotlin
* **IDE**: Android Studio
* **UI**: XML Layout
* **Build Tool**: Gradle

---

## 📌 주요 기능

* 📱 스마트폰 상품 목록 조회
* 🔍 상품 검색 및 필터 기능
* 🛒 장바구니 기능
* 👤 사용자 정보 관리
* 💳 결제 기능 (예정 또는 일부 구현)
